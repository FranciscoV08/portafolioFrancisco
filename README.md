# 🌐 Portafolio Web Personal

Este proyecto es un **portafolio web simple** que permite mostrar mis **proyectos y habilidades de desarrollo** utilizando **Vite, TypeScript y React Router DOM**.

📌 Creado como demostración de conocimientos en frontend y manejo de rutas con React.

---

## 🚀 Tecnologías utilizadas
- **Vite ⚡** → entorno de desarrollo rápido  
- **React ⚛️** → librería de UI  
- **TypeScript 🟦** → tipado estático y seguridad de código  
- **React Router DOM 🔀** → navegación entre páginas

---

## ✨ Funcionalidades
✅ Navegación entre páginas del portafolio  
✅ Visualización de proyectos y detalles  
✅ Diseño responsive y simple  
✅ Código modular y limpio
